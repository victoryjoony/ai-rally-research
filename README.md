# AI Rally Research

미국 주식의 AI 랠리 재개를 가정한 24개월 투자 리서치입니다.

- 주가 기준: 2026-10-23 정규장 종가
- 자료 열람: 2026-10-26
- 12개 기업의 가격·EPS·PER·가치 시나리오 비교
- 검색, 섹터 필터, 약세·기준·강세 시나리오, 가치 계산기
- 기업 실적 및 시장 자료 출처 포함

보고서는 index.html 하나로 동작합니다. 외부 링크를 제외하면 외부 의존성이나 API 키가 없습니다.
